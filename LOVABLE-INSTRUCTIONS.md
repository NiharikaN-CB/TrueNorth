# TrueNorth Lovable Instructions

Use this when working in Lovable, v0, Gemini CLI, Copilot, Replit, or another tool without native AGENTS.md support.

Read `AGENTS.md` first — it is the source of truth for this project. Details live in `agent_docs/`.

For UI refinement, preserve the existing architecture and data model. Do not use a visual tool to restructure the core storage, canvas, AI, or privacy architecture after functionality is established.

Plan before coding, build one feature at a time, verify before moving on.

TrueNorth must remain:
- feminine, elegant, nostalgic, personal;
- local-first and privacy-preserving;
- focused on the user's feelings rather than decoding another person;
- free of clinical/therapy claims;
- responsive on mobile and desktop.
