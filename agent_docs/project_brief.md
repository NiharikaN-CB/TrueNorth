# TrueNorth Project Brief

## Vision

TrueNorth is **“A calmer way to date.”**

It is a private, women-centered digital journal and reflection companion for the moments after dating interactions.

The product is designed around a simple interruption to the modern dating overthinking loop:

> Something happened → I feel unsettled → I reflect on it → I understand myself better → I recover → I notice patterns over time.

TrueNorth should help the user return attention to her own feelings, needs, boundaries, and values instead of trying to decode another person's behavior.

## Emotional Experience

TrueNorth should feel:

- Feminine
- Elegant
- Nostalgic
- Personal
- Soft
- Warm
- Calm
- Tactile
- Private

The visual inspiration is a rosy seaside sunset combined with a handmade digital scrapbook/planner.

It should feel like a cherished physical notebook translated into a digital environment.

## What TrueNorth Is Not

TrueNorth is not:

- a dating coach;
- a therapist;
- a clinical mental-health tool;
- a relationship decision-maker;
- a generic AI chatbot;
- a social/dating feed;
- a productivity/task-management app.

## Core User Promise

A user should be able to open TrueNorth after a dating interaction, immediately write or draw what happened, explicitly ask for reflection, and receive a gentle structured response without creating an account.

## Core Conventions

### Privacy first

Journal data remains local in the browser. The AI only receives the necessary current-entry text after explicit user action.

### Reflection over advice

The AI helps the user notice feelings and values. It does not decide what the relationship means or what the user should do.

### Reliability before polish

Build the core system in small stages. Verify each stage before moving on. Visual refinement comes after the core experience is dependable.

### Personal, not clinical

Avoid sterile dashboards, clinical language, excessive forms, and generic productivity patterns.

### Decoration is subordinate

Roses, seaside elements, shells, flowers, bows, stars, photos, paper, and tape can enrich the notebook feeling, but they must never obscure writing or reflection.

## Success

The experience succeeds when a user can reliably go from:

> Something happened

to:

> I feel unsettled

to:

> I open TrueNorth

to:

> I write / draw

to:

> I press Reflect

to:

> TrueNorth reflects my experience

to:

> I notice my feelings and values

to:

> I feel a little more grounded

The product should not leave the user feeling like she entered another productivity system.

## Core Metrics

- Time-to-value: under 2 minutes from starting the first journal entry to receiving the first AI reflection.
- Activation: 70% of new users complete their first journal entry and AI reflection.

## Working Style

This is a solo, AI-assisted build with a 40-hour target.

Use role-based AI workflows:

- Claude plans.
- Antigravity builds.
- Lovable refines UI.
- ChatGPT explains and debugs.

Never ask one agent to rewrite the entire application as one giant task.
